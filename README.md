# Online Educational Platform (SHAD)

## Software Engineering Course Project

### Project Description

This project aims to design and analyze an integrated online educational platform similar to SHAD.

The system focuses on:

- Service-Oriented Architecture (SOA)
- Scalability
- Service Integration
- Educational Management
- Online Learning Services
