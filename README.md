# Online School Learning Platform (SHAD-Like System)

## Software Engineering Course Project
### Based on Ian Sommerville - Software Engineering (10th Edition)

---

## Project Overview

This project presents the complete Software Development Life Cycle (SDLC) of an integrated online school learning platform inspired by the SHAD educational network.

The system is designed as a scalable educational platform that supports students, teachers, parents, school administrators, and system administrators through a unified environment for online learning, communication, assessment, content management, and educational monitoring.

A major focus of this project is on:

- System Engineering Principles
- Service-Oriented Architecture (SOA)
- Scalability and Maintainability
- Requirements Engineering
- UML-Based Modeling
- Software Architecture and Design
- Testing and Evolution Planning

---

## Project Objectives

- Analyze and model a large-scale educational system.
- Apply Software Engineering concepts throughout the SDLC.
- Perform System Engineering analysis.
- Design a Service-Oriented Architecture.
- Produce professional software artifacts and documentation.
- Ensure traceability from requirements to implementation.

---

## System Description

The platform provides services including:

- User Management
- Authentication and Authorization
- Online Classes
- Educational Content Management
- Assignment Management
- Online Examinations
- Attendance Management
- Internal Messaging
- Notification Services
- Educational Reporting
- School Administration Services

The system is designed to support a large number of concurrent users while maintaining performance, security, and availability.
